# Forever 专精天梯 · 天赋模拟器

魔兽世界 Forever 九职业 27 个专精，从 1 级到 60 级每一级的强弱排名和最佳加点。

**在线打开：https://sduckyduck.github.io/wow-forever-talents/**

- 按 Wowhead Forever 天赋计算器的规则逐级模拟加点（10 级起每级 1 点，每行需投入 5 点，第 7 行最早 40 级），可切换 Legacy「Talented」（9 级起有天赋点）
- 升级综合榜、纯天赋提升榜，以及 60 级输出 / 坦克 / 治疗榜
- 点任意专精看最佳加点：三系天赋树、逐级加点顺序、一键在 Wowhead 打开同一套加点
- 九职业技能学习表（用 BlizzCon 试玩 38 级技能书逐条核对）、种族天赋、Legacy 传承
- 全中文，国服官方译名 / 沿用后续版本译名 / 暂译分别标注，保留英文原文方便核对

## 数据来源

- 天赋：[Wowhead Forever 天赋计算器](https://www.wowhead.com/forever/talent-calc)（BlizzCon 2026 试玩数据，试玩封顶 38 级，部分等级为推算）
- 技能学习等级：Wowhead Forever 技能库（目前是 Classic 数据镜像）+ BlizzCon 2026 试玩技能书
- 中文：Wowhead 国服 Classic 数据库官方译名；其余为人工翻译并标注
- 强弱排名是模型估算（天赋逐个估值 + 职业基础强度），**不是实测**，beta 开放后会再校准
